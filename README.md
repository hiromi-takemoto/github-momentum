# GitHub Momentum

**star数の合計ではなく、「いま1日あたり何star増えているか」でGitHubリポジトリを並べるサイト。**

公開URL: https://hiromi-takemoto.github.io/github-momentum/

---

## なぜ作ったか

GitHubのトレンド系ツールはたくさんあります。しかしそのほとんどが見せているのは **累計star数の順位** です。

これは「過去の合計」です。10年かけて集めた24万starも、今週集めた1万starも、同じ「star数」として並びます。
**そのプロジェクトが今も伸びているのか、それとも過去の遺産なのかは分かりません。**

実際に測ってみると、この2つは別物でした。

| 順位 | 累計star順 | 勢い順（1日あたりのstar増加数） |
|---|---|---|
| 1 | facebook/react (248k) | torvalds/linux (147/日) |
| 2 | torvalds/linux (245k) | ollama/ollama (94/日) |
| 3 | microsoft/vscode (190k) | langchain-ai/langchain (65/日) |
| 4 | ollama/ollama (180k) | **facebook/react (58/日)** |

reactは累計star数では1位ですが、いまの伸びはollamaの約6割です。
**「reactは成熟しきった」「ollamaは今まさに伸びている」——これは累計star数のランキングからは読み取れません。**

このサイトは、その読み取れなかった部分だけを見せます。

## 仕組み

```
[1] GitHub Actions が毎日1回起動する（サーバー費用0円）
      ↓
[2] GitHub Search API から上位1000件のリポジトリを取得（10リクエスト）
      ↓
[3] 前日までの記録と比べて「1日あたりのstar増加数」を計算する
      ↓
[4] 表示に必要な分だけを data/latest.json に書き出してコミットする
      ↓
[5] GitHub Pages 上の index.html がそれを読んで表示する
```

計算はすべて [1]〜[4] のバックエンド側で済ませ、ブラウザには表示に必要なデータだけを渡しています。

## 設計で意識したこと（すべて実測値）

| 項目 | 数値 | 内容 |
|---|---|---|
| 表示までの時間 | **37ms** | 外部ライブラリ・CDN・Webフォントを一切使わない |
| 外部への通信 | **1回** | `data/latest.json` の取得のみ |
| 転送量 | **19KB** | gzip後。1000件から表示に必要な200件へ絞り込み |
| 1日の記録 | **30KB** | 名前とstar数のみ保存（全項目だと445KB＝1年159MB） |
| 1年後の容量 | **11MB** | 上記の最小化により93%削減 |
| API使用率 | **0.2%** | 1日10リクエスト（上限は毎時5000） |
| コントラスト比 | **最低6.1** | WCAG AA基準（4.5）を全パターンで上回る |

### 数値で検証した箇所

- **勢いの計算**: 既知の値を入れた検証用データを流し込み、出力400件すべてを手計算と突き合わせて一致を確認
- **色**: canvasに1px描画して実RGBを取得し、全パターンのコントラスト比を機械的に測定
- **スマホ表示**: 実測で表の全幅が860pxあり、画面幅375pxに対して主役の「勢い」列が画面外にあることを発見。列構成を変えて349pxに収めた
- **データの正直さ**: 記録が1日分しかない日は、推定値で埋めず `null` を返し「計測中」と表示する

## このサイトが時間とともに強くなる理由

GitHub Trending には過去ログがありません。ランキングから外れたリポジトリの記録は消えます。

このサイトは毎日の記録を `data/snapshots/` に残し続けます。
**コードはコピーできても、蓄積された日数はコピーできません。**
公開初日は1日分ですが、そこから毎日1日分ずつ、他では手に入らないデータになっていきます。

## 分かっている限界

- star 5000未満のリポジトリは対象外です。急上昇中でもstarが少ないうちは載りません
- 勢いは1日1回の記録の差分なので、1日の中の動きは見えません
- 公開直後は記録が少ないため、勢いの精度は日数とともに上がります

## 動かし方

```bash
node collect.mjs        # データを取得して data/ を更新する
```

- Node.js 22 以上。**依存パッケージなし**（`package.json` もありません）
- `GITHUB_TOKEN` 環境変数があればAPI制限が緩和されます（GitHub Actions では自動で設定されます）
- サイトの表示は `index.html` を静的配信するだけです

## 構成

```
collect.mjs                     データ取得と勢いの計算（Node.js・依存なし）
index.html                      画面の全て（HTML/CSS/JS を1ファイルに）
data/latest.json                サイトが読むデータ
data/snapshots/YYYY-MM-DD.json  毎日の記録
.github/workflows/collect.yml   毎日6時(JST)に自動実行
SPEC.md                         仕様書
```
